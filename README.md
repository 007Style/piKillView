## What is piKillView?

**piKillView** is the standalone, high-performance graphical companion to [piKill](https://github.com/007Style/piKill) — the Chudnovsky-powered π calculation engine built in pure Go. Where piKill dominates the terminal, piKillView gives infinite precision a vibrant, real-time visual canvas.

Watch millions of digits stream through an animated matrix rain header into a 10MB color-coded circular display. Observe live digit frequency histograms converge toward a perfect 10% distribution, track CPU core dials as they shift from green to amber to roaring red, and watch worker dots pulse in real-time as multi-threaded Chudnovsky workers crunch through terms.

Packaged as a single self-contained native binary with zero external runtime dependencies, piKillView is built entirely in Go using [Fyne v2](https://fyne.io). No installers, no web runtimes, no heavyweight browser wrappers — just raw Go performance, immediate startup, and native GPU-accelerated rendering across macOS, Linux, and Windows.

## Features

- **Animated Digit Rain Header**: Matrix-style digital waterfall cascading behind a pulsing, glowing π symbol rendered at 30 FPS.
- **Color-Coded Digit Display**: Every digit (`0`–`9`) has a distinct vibrant palette color for instant visual pattern recognition.
- **10MB Ring Buffer Viewer**: High-capacity circular digit buffer — read-only, selectable, auto-scrolling with smooth lock/unlock toggling.
- **Viewing Range Indicator**: Real-time display indicating the exact global span of visible digits (`"Viewing digits X–Y"`).
- **Multi-Core Thread Slider**: Effortless concurrency control: Single / 1× / 2× / 3× / 4× logical CPUs (including "MAXIMUM OVERDRIVE").
- **Full Run Control**: Instant Start, Stop, Pause, and Resume from existing output files.
- **Digit Frequency Histogram**: Live updating 0–9 bar chart tracking digit distribution as it asymptotically converges to 10.00% each.
- **Digits/Sec Sparkline**: Rolling 60-second real-time throughput chart showing calculation bursts.
- **Worker Pulse Indicators**: Grid of dynamic LED indicators tracking up to 48 concurrent workers in real-time.
- **CPU Arc Dials**: Per-logical-core load indicators shifting dynamically from green (`<50%`) to yellow (`50-80%`) to fiery red (`>80%`).
- **Speed Gauge**: High-visibility analog needle dial displaying instantaneous digits calculated per second.
- **Elapsed High-Res Timer**: Precision runtime tracking in `HH:MM:SS.mmm` format.
- **Round & ETA Indicator**: Displays current Chudnovsky series iteration and estimated time to complete the active round.
- **Live Memory Usage Tracker**: Displays real-time heap allocation and total memory footprint.
- **Milestone Celebration Toasts**: Non-intrusive animated achievement toasts triggered at key milestones (1K, 10K, 100K, 1M, 10M, 100M, 1B digits 🎉).
- **High-Speed Search (Cmd+F / Ctrl+F)**: Substring search powered by Boyer-Moore-Horspool algorithm — instantaneous scanning across millions of characters.
- **"Find My Birthday"**: One-click lookup for `MMDDYYYY` or custom calendar dates inside the computed π stream.
- **Match Navigation**: Next/Previous match cycling with in-view highlighted jump coordinates.
- **Custom Output Directory**: Stream computed digits directly to any disk directory or drive without locking the working path.
- **Resume Capability**: Load and verify existing `pi-*.txt` files and resume computation from the exact last digit offset.
- **Precision Lock**: Set target limits to automatically halt calculation upon reaching a desired digit count (e.g., exactly 1,000,000 digits).
- **Configurable Auto-Save**: Background disk flush interval selectable between 10s, 30s, 1m, or 5m.
- **Snapshot Export**: Instantly export the current in-memory ring buffer to a standalone text file on demand.
- **Dark / Light Theme Toggle**: Seamless UI theme switching with custom handcrafted palettes optimized for readability.
- **π Trivia Ticker**: Continuous marquee with 40 curated mathematical and historical π facts along the bottom bar; pauses smoothly on mouse hover.
- **Collapsible Session Log**: Timestamped terminal log recording all lifecycle events, milestone hits, search completions, and errors.
- **Keyboard Shortcuts**: Full hotkey support (`Space` to toggle Start/Stop, `Cmd+F` / `Ctrl+F` to search, `Cmd+S` / `Ctrl+S` for snapshot, `Esc` to dismiss modals).

## The Development Journey

### From Terminal to Canvas
The story began with [piKill](https://github.com/007Style/piKill) — a pure Go terminal utility built to push modern multicore processors to their absolute theoretical limits computing digits of π using the Chudnovsky algorithm. piKill was lightning-fast, lean, and offered its famous `-tttt` (MAXIMUM OVERDRIVE) mode.

Yet watching raw numbers fly by on a CLI terminal left us wanting more: What does the distribution look like as it converges? What does CPU saturation feel like across all 16 or 32 cores? How fast can you locate your birthday in the first million digits while the engine is actively computing them?

**piKillView** was born to answer those questions.

### The Algorithm
piKillView uses the **Chudnovsky algorithm**, published by the Chudnovsky brothers in 1988. It is based on Ramanujan's hypergeometric series and yields roughly 14.181647462725477 digits of π per term:

$$\frac{1}{\pi} = 12 \sum^\infty_{k=0} \frac{(-1)^k (6k)! (545140134k + 13591409)}{(3k)!(k!)^3 (640320)^{3k + 3/2}}$$

Each round computes high-precision integer terms using Go's `math/big`, breaking giant multiplications into work-stealing parallel chunks distributed across worker goroutines.

### The Threading Model & MAXIMUM OVERDRIVE
Concurrency is handled through work-stealing atomic task queues. When you slide the thread selector from `1×` up to `4×` logical CPUs, piKillView scales worker goroutines over Go's runtime scheduler, saturating hyperthreads to maximize ALU and memory bandwidth.

### Why Fyne?
We chose **Fyne v2** because it aligns with our core philosophy:
- **Pure Go Ecosystem**: Native compilation without needing Electron, Chromium, or Node.js runtime bloat.
- **Single Binary Artifact**: Everything — fonts, shaders, rasterizers, and logic — compiles into one executable.
- **Cross-Platform Parity**: macOS, Linux, and Windows all share identical styling and performance characteristics.

### Technical Challenges

1. **Animated Matrix Digit Rain at 30 FPS**:
   Rendering hundreds of streaming glyphs with alpha-decay trails without eating CPU cycles meant implementing custom raster rendering routines in Go that cooperate with Fyne's canvas update loop without blocking calculation channels.

2. **10MB Ring Buffer with Color-Coded Segments**:
   Holding up to 10,000,000 characters in a circular memory buffer while allowing smooth user selection, auto-scrolling, and fast sub-segment colorizing required custom zero-copy string slice mapping.

3. **Sub-Millisecond Boyer-Moore-Horspool Search**:
   Scanning a moving 10MB memory buffer for arbitrary patterns needed a specialized search implementation that runs on a detached goroutine without locking the engine write mutex.

4. **Multi-Platform Native GitHub Actions Matrix**:
   Cross-compiling Fyne with CGO support across macOS (Intel + Apple Silicon), Linux (x86_64 + ARM64), and Windows required tailored native GitHub Actions runner pipelines ensuring zero-friction releases.

## Building from Source

### Prerequisites

- **Go 1.22+** (tested with Go 1.24)
- **C Compiler (CGO required by Fyne graphics drivers)**:
  - **macOS**: Xcode Command Line Tools (`xcode-select --install`)
  - **Linux (Ubuntu/Debian)**: `sudo apt-get install gcc libgl1-mesa-dev xorg-dev libxcursor-dev libxrandr-dev libxinerama-dev libxi-dev`
  - **Linux (Fedora/RHEL)**: `sudo dnf install gcc libX11-devel libXcursor-devel libXrandr-devel libXinerama-devel libXi-devel mesa-libGL-devel`
  - **Windows**: MinGW-w64 (`gcc`)

### Build Steps

```bash
# 1. Clone the repository
git clone https://github.com/007Style/piKillView.git
cd piKillView

# 2. Download Go dependencies
go mod download

# 3. Build the binary
go build -o piKillView .

# 4. Run piKillView
./piKillView
```
